### Access to Everyday Life: Seattle Sidewalk Accessibility  
*Dubstech Datathon 2026 | Data Analysis & Visualization*  
🔗 https://reneeemlee.github.io/dubstech-datathon-2026/
- Analyzed Seattle sidewalk accessibility using **Project Sidewalk** and **Seattle GeoData** datasets.
- Investigated the **severity, frequency, and spatial distribution** of accessibility barriers across neighborhoods.

- Identified clustering of high-barrier areas, highlighting **systemic infrastructure inequities**.
