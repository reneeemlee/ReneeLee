## 💻 Projects

### 🗺️ Access to Everyday Life: Seattle Sidewalk Accessibility  
*Dubstech Datathon 2026 | Data Analysis & Visualization*  
🔗 https://reneeemlee.github.io/dubstech-datathon-2026/

- Analyzed Seattle sidewalk accessibility using **Project Sidewalk** and **Seattle GeoData** datasets.
- Investigated the **severity, frequency, and spatial distribution** of accessibility barriers across neighborhoods.
- Developed an **Accessibility Score** to quantify neighborhood-level mobility challenges.
- Identified clustering of high-barrier areas, highlighting **systemic infrastructure inequities**.
- Found the **Industrial District** to have the highest overall accessibility burden, indicating a priority area for intervention.
- Created **interactive Tableau dashboards** to communicate findings clearly to non-technical audiences.

**Tools:** Tableau Public, data cleaning, spatial analysis  
**Team:** Renée Lee, Celine Chen, Heidi Ngo
